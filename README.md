# EMNSTRIKE

**EMNSTRIKE** is a tactical first-person shooter (FPS) game developed by **E.M.N Studio** using the proprietary **EMN+ programming language**.

## 🎮 Game Mechanics

- **Round System:** Round-based gameplay.
- **Combat System:** First-person combat and weapon mechanics.
- **Market System:** In-game equipment purchasing system.
- **Economy System:** Player money and in-game economy.
- **Map System:** Tactical FPS maps.
- **User Interface:** Interactive menus and gameplay interface.
